# Hackathon demo path

1. Configure Supabase and run migrations plus seed.
2. Create a demo account at `/signup`.
3. Complete onboarding and choose Full Stack Developer.
4. Open Agent Activity and run career analysis; show the persisted Profile -> Skill Gap -> Roadmap -> Resource trace.
5. Open Learning Hub, inspect the active step and curated resources, then launch an assessment.
6. Submit a weak result to show BKT feedback, the adaptive roadmap run, and the Mentor explanation.
7. Open Agent Activity to show the bounded agent flow, persisted messages, and final negotiation decision.
8. Ask the AI Mentor why a skill is prioritized.
9. Change the career through the career UI when configured and show the previous-versus-new roadmap comparison.

If Gemini is unavailable, explain that the displayed assessment and Mentor outputs are deterministic or curated fallbacks. Do not present them as live model generations. Cohort insights currently demonstrate a privacy-safe insufficient-data state; market insights are clearly labeled curated signals.
